# PAPPA на JavaScript (Node)

Четвёртый по счёту порт после референса Python, C++ и Go. **Без зависимостей**:
только стандартная библиотека Node (ESM). Требуется Node ≥ 20 (проверено на 24.16).

## Структура

```
js/
  package.json              {"type": "module"} — все файлы ESM
  pappa/
    signal.js               медиана/перцентиль/MAD/окна по кольцу (поведение numpy)
    linalg.js               МНК через QR Хаусхолдера, базис Чебышёва (Кленшоу)
    cleaner.js              авто-очистка выбросов (iqr): медианный фильтр + усы Тьюки
    detector.js             детектор ям: узкая/широкая медиана -> индикатор в MAD-ах
    model.js                PatchApproximator: локальные степени, smoothstep-смешивание,
                            оконный гауссов фичер ям, свип степеней одним накоплением Грама
    document.js             запись папки образца (sample.json + sections/NN.pappa.json)
    conformance.js          сверка с конформанс-векторами (допуски как у C++/Go/C)
    conformance.test.js     тесты встроенным раннером (node --test)
  cmd/
    conformance.js          CLI: прогон векторов (код 0/1/2)
    pappa.js                CLI: CSV -> папка образца
```

## Запуск

```powershell
# конформанс-векторы (4/4)
node js/cmd/conformance.js

# тесты
cd js; node --test; cd ..

# пайплайн: CSV -> папка образца
node js/cmd/pappa.js --input python/synthetic_data.csv `
                     --out-dir samples/synthetic_sphere_js --name synthetic_sphere

# официальные ворота против референса Python
python python/studies/verify_port.py --py-dir samples/synthetic_sphere `
                                     --cpp-dir samples/synthetic_sphere_js
```

## Замечания

* Документ порта несёт `software.language = "js"` и `pappa_version = "0.1.0"`;
  в остальном `sample.json`/`sections/NN.pappa.json` повторяют C++/C/Go **поле в поле** —
  поэтому папки от разных портов сравниваются численно `verify_port`.
* Числа пишутся как `%.17g`-эквивалент (`num()`): целые без дробной части, иначе
  17 значащих цифр — гарантирует round-trip при разборе.
* Ключ `pit_terms` пишется у **каждого** патча, когда модель с ямами (включая пустой
  список) — этого требует загрузчик Python-референса.
* Тайминги: 10 сечений × 6000 точек обрабатываются за ~0.2 с суммарного времени
  обучения (V8, JIT прогревается на первом сечении: 43 мс -> 12 мс).
