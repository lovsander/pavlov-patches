# python/research/ — архив исследований и отклонённых гипотез

Здесь лежат эксперименты, которые **не входят в пакет `appa`** и не являются
рекомендациями: это «красные флаги» и тупиковые ветки, которые полезно помнить.
Код рабочий, запускается напрямую (папка сама добавляет корень `python/` в
`sys.path`, данные и рисунки считаются от `python/`).

| файл | что это | итог |
|---|---|---|
| `rejected_node_on_pit.py` | гипотеза «ставить узлы (стыки патчей) на дно ям» | ОТКЛОНЕНА: локально лучше, в сумме −17%; дно ям дрейфует 15–20° между сечениями, `overlap_train=15°` заставляет оба соседних полинома видеть яму, узел ставит яму на ~63% полуширины окна (хуже число Лебега), а `overlap_train=0` ломает сшивку (RMSE ×4–7). Подробности — в docstring файла и в CONTEXT §14 |

Правила для этой папки:

* сюда попадают только ЗАВЕРШЁННЫЕ исследования с уже понятным выводом;
* вывод («отклонена / подтверждена / почему») обязан быть в docstring файла —
  чтобы не пришлось восстанавливать историю по коммитам;
* ничего отсюда не импортируется в `appa/`, `studies/`, `demos/`, `generator/`.

Запуск, например:

```
C:/Users/maxan/miniconda3/envs/geom-toolkit/python.exe research/rejected_node_on_pit.py
```
