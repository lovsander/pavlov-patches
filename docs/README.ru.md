# Docs

[English](README.md) · **Русский**

- `method.md` — формальное описание PAPPA (математика + псевдокод), по-русски:
  [`method.ru.md`](method.ru.md).
- `embedded.md` — выполнимость C++-ядра на микроконтроллерах
  (Arduino/Cortex-M/ESP32): измеренная стоимость по фазам, память, вердикты по
  платам, план оптимизации с влиянием на паритет. Пока **только по-русски** —
  английский перевод ещё не сделан.
- `assets/` — картинки для README и презентаций: рисунки метода (`method_*.png`,
  собираются `python/studies/make_method_figures.py`, числа — в `method.md` §14) и
  графики исследовательских скриптов из `python/pappa/viz/`, закоммиченные как
  финальные ассеты.

## Языки документации

Канонический язык — английский (`README.md`, `docs/method.md`), перевод лежит рядом
с оригиналом как `<имя>.<язык>.md` (ISO 639-1) и начинается строкой-переключателем
языка. `python tools/check_docs_i18n.py` проверяет пары (переключатель есть в обоих
файлах, структура разделов совпадает) и не пропускает перескоки языка внутри файла —
английский абзац в русском документе или кириллическую прозу в английском.
