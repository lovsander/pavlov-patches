# PAPPA на C (C99)

Порт метода **без зависимостей**: только `<math.h>`, никакого malloc, JSON или
файлового ввода-вывода. Размеры — фиксированные массивы (`PP_MAX_*` в `pappa.h`),
поэтому код одинаково годится и для хоста, и для микроконтроллера (там достаточно
уменьшить ёмкости).

## Что внутри

| файл | назначение |
|------|-----------|
| `pappa.h` | API: модель (патчи, фичер ям), детектор трещин, авто-очистка |
| `pappa.c` | реализация: сигнальные утилиты как numpy, МНК через QR Хаусхолдера, базис Чебышёва, оконный гаусс, partition of unity |

Внутри — те же наработки, что вернулись в C++/Go: **свип степеней одним
накоплением матрицы Грама в базисе Чебышёва** (префиксное свойство) + RMSE по
явным остаткам (Кленшоу), данные центрируются. Легаси-режим `coord_mode = "raw"`
оставлен на прежнем пути (базис Чебышёва требует x ∈ [-1, 1]).

Метрики документа (amplitude/mean/rmse-статистика/correlation) пока не считаются —
конформанс-векторы проверяют степени, коэффициенты, термины фичера и контур; метрики
добавим вместе с писателем документа (следующий шаг).

## Проверка (векторы конформанса)

```bash
python python/studies/check_c_port.py            # -> код 0, если всё сошлось
```

Скрипт собирает `c/pappa.c` в DLL (`gcc -shared`) и вызывает её через `ctypes`:
в C-коде нет JSON, векторы читает Python, допуски — те же, что у C++/Go
(контур 1e-6 мм, коэффициенты `max(1e-8, 1e-9·|c|)`, детектор/очистка — доля точек).

**Результат:** 4/4 вектора, степени по патчам совпали точно
(`[12,10,12,12,14,10,12]` и `[14,14,12,14,14,10,12]`), коэффициенты 8.7e-11 и
1.7e-9, термины фичера 1.9e-13, контур 3.0e-14 и 3.1e-13 мм.

## Замечание по векторам (нашлось при проверке)

Векторы `vector_03` (детектор) и `vector_04` (очистка) несут **пустые ожидания**:
`zones_deg = []`, `pits_deg = []`, `n_outliers = 0`, `mask_true_indices = []`.
То есть эти две ступени сейчас проверяются тривиально (порт C++, Go и C все
проходят «ни на чём»). Причина — входной профиль в этих векторах гладкий:
детектор `band` на нём не находит зон, а очистка — выбросов. Стоит поправить
генератор (`python/studies/make_conformance.py`), чтобы во вход этих векторов
попадали реальные ямы и всплески.
